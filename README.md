# MHRise Build Tools

Core build-planning and equipment-reuse optimizer for Monster Hunter Rise: Sunbreak.

The project currently focuses on a testable TypeScript domain library. A future web UI will consume the algorithm packages after the rules and optimization results are validated.

## Workspace

- `packages/core`: domain rules and build optimization algorithms
- `packages/data`: normalized source data and localization mappings
- `apps/web`: future web UI
